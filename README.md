# LingoPop for Windows

LingoPop is a tray app that translates, fixes, rewrites and explains selected text with the AI provider of your choice. This repository is the Windows version, built with Tauri v2 on top of an OS-agnostic Rust core, and is a sibling of the macOS app [`slucheninov/lingopop`](https://github.com/slucheninov/lingopop).

**Status:** pre-alpha, Phase 1 (core foundations). The real README is written in Phase 5.
